# Security Policy

## Supported Versions

| Version | Supported          |
|---------|-------------------|
| 2.x     | :white_check_mark: |
| 1.x     | :x:               |

## Reporting a Vulnerability

If you discover a security vulnerability in BenzaTracker, please report it
privately **before** creating a public issue.

**Do not** file a public GitHub issue — instead, send a detailed report to:

**francesco.castaldi@outlook.com**

Please include:

- A brief description of the issue
- Steps to reproduce
- Affected versions
- Any potential impact or exploit scenario

You should receive an acknowledgment within **48 hours**. If you don't hear
back, feel free to follow up.

### What to expect

- Confirmation that the report has been received
- An assessment and timeline for a fix
- Notification when the fix is deployed
- Credit in the release notes (if desired)

We take all security reports seriously and will investigate every report as
quickly as resources allow.

## Getting help

If you run into a problem:

1. **Check the existing issues** — someone else may have hit the same thing.
   Search [open and closed issues](https://github.com/FrancescoCastaldi/BenzaTracker/issues).

2. **Open a GitHub Discussion** — use the
   [Discussions](https://github.com/FrancescoCastaldi/BenzaTracker/discussions)
   tab for Q&A, ideas, and general help.

3. **File a bug report** — if you've confirmed it's a bug, open a
   [Bug Report](https://github.com/FrancescoCastaldi/BenzaTracker/issues/new?template=bug_report.yml).

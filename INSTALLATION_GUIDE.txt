🚀 QUICK START
══════════════════════════════════════════════════════════════

Simplest way to install and run BenzaTracker:

  1. Download and extract the BenzaTracker ZIP file
  2. Double-click on "install_and_run.bat"
  3. Let it install everything automatically
  4. Your app will launch automatically when done!


📋 WHAT INSTALL_AND_RUN.BAT DOES
══════════════════════════════════════════════════════════════

The install_and_run.bat script automatically:

  ✓ Checks if Python 3.8+ is installed
  ✓ Creates a virtual environment
  ✓ Installs all dependencies from requirements.txt
  ✓ Installs PyInstaller for building the executable
  ✓ Compiles the Python code into a Windows .exe file
  ✓ Launches BenzaTracker as a native application window

No manual steps needed - it's all automated!


⚙️ REQUIREMENTS
══════════════════════════════════════════════════════════════

• Windows 7 or newer (7, 8, 8.1, 10, 11)
• Python 3.8 or newer (FREE from https://www.python.org)
• 500 MB free disk space
• Internet connection (for downloading dependencies)


📥 INSTALLATION STEPS
══════════════════════════════════════════════════════════════

1. INSTALL PYTHON (if not already installed)
   └─ Go to: https://www.python.org/downloads/
   └─ Download Python 3.11 or newer
   └─ **IMPORTANT:** Check "Add Python to PATH" during install
   └─ Click "Install Now"

2. DOWNLOAD BENZATRACKER
   └─ Download the BenzaTracker ZIP from GitHub
   └─ Extract it to a folder (e.g., C:\Users\YourName\BenzaTracker)

3. RUN INSTALL_AND_RUN.BAT
   └─ Open the extracted BenzaTracker folder
   └─ Double-click "install_and_run.bat"
   └─ A command window will open
   └─ Wait for the process to complete (~2-5 minutes)
   └─ BenzaTracker will launch automatically!

4. USE BENZATRACKER
   └─ The GUI window will open
   └─ Add refuel entries as needed
   └─ Export PDF reports
   └─ Close the window to exit


🔄 RUNNING BENZATRACKER AGAIN
══════════════════════════════════════════════════════════════

After the first installation:

  OPTION A: Double-click install_and_run.bat again
  └─ Quickest way, rebuilds everything fresh

  OPTION B: Navigate to "dist" folder and double-click BenzaTracker.exe
  └─ Runs the pre-compiled executable directly
  └─ Much faster if you just want to use the app


⚠️ TROUBLESHOOTING
══════════════════════════════════════════════════════════════

PROBLEM: "Python is not installed or not in PATH"
SOLUTION:
  • Reinstall Python from https://www.python.org
  • Make SURE to check "Add Python to PATH" ✓
  • Restart your computer
  • Try again

PROBLEM: Installation takes too long
SOLUTION:
  • This is normal on first run (2-5 minutes)
  • Your computer is building the Windows executable
  • Be patient and don't close the window

PROBLEM: "Failed to install dependencies"
SOLUTION:
  • Check your internet connection
  • Try running install_and_run.bat again
  • Ensure you have write permissions in the folder

PROBLEM: BenzaTracker crashes immediately
SOLUTION:
  • Check if any antivirus blocked the executable
  • Try running from "dist\BenzaTracker.exe" directly
  • Make sure requirements.txt is in the same folder

PROBLEM: "Command 'python' not recognized"
SOLUTION:
  • Verify Python is installed: Open CMD and type "python --version"
  • If not found, reinstall Python with PATH option checked

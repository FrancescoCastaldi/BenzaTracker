BENZATRACKER - PDF EXPORT FEATURE QUICK START
===============================================

WHAT'S NEW?
-----------
BenzaTracker now supports exporting refuel data as professional PDF reports!

WHAT YOU NEED TO DO
-------------------

1. INSTALL DEPENDENCIES
   $ pip install -r requirements.txt
   
   (This installs reportlab, needed for PDF generation)

2. UPDATE gui.py FILE
   
   ☐ Add these imports (after line 16):
     from .pdf_report import PDFReportGenerator
     from pathlib import Path
     from tkinter import filedialog
   
   ☐ Add this button in _build_form() method (after "Salva rifornimento" button):
     tb.Button(
         button_frame, text="Esporta PDF", 
         command=self._on_export_pdf, 
         bootstyle="info"
     ).pack(side=RIGHT, padx=5)
   
   ☐ Add this method (after _on_submit method):
     def _on_export_pdf(self) -> None:
         """Export current data to PDF report."""
         if not self.entries:
             messagebox.showwarning(
                 "Nessun dato", 
                 "Non ci sono dati da esportare"
             )
             return
         
         file_path = filedialog.asksaveasfilename(
             defaultextension=".pdf",
             filetypes=[("PDF files", "*.pdf"), ("All files", "*.*")],
             initialfile="benzatracker_report.pdf"
         )
         
         if file_path:
             try:
                 generator = PDFReportGenerator(file_path)
                 generator.generate_report(self.entries)
                 messagebox.showinfo(
                     "Esportazione completata",
                     f"Report salvato in: {file_path}"
                 )
             except Exception as e:
                 messagebox.showerror(
                     "Errore esportazione",
                     f"Errore durante l'esportazione: {str(e)}"
                 )

3. TEST THE FEATURE
   $ python main.py
   - Add some test refuel entries
   - Click "Esporta PDF"
   - Choose a location to save
   - Open the generated PDF

WHAT THE PDF INCLUDES
---------------------
✓ KPI Summary (total spent, liters, average price, etc.)
✓ Best price and worst price with dates
✓ Detailed table of all refuel entries
✓ Professional formatting with colors
✓ All text in Italian
